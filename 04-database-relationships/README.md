# Database Relationships

## 🇮🇷 فارسی

در این فصل دیتابیس پروژه BookStore را گسترش می‌دهم.

تا اینجا فقط یک جدول داشتم، اما در پروژه‌های واقعی داده‌ها در چندین جدول ذخیره می‌شوند و این جدول‌ها با یکدیگر ارتباط دارند.

در این فصل اولین ارتباط بین جدول‌ها را ایجاد می‌کنم و با مفهوم Foreign Key به صورت عملی آشنا می‌شوم.

---

### آنچه یاد می‌گیرم

* طراحی چند جدول
* Primary Key
* Foreign Key
* One-to-Many Relationship
* ایجاد داده‌های مرتبط

## 🇺🇸 English

In this chapter, I expand the BookStore database by creating multiple related tables.
