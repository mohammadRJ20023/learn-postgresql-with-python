# Lesson 01 - Installing PostgreSQL

در این فصل PostgreSQL را روی سیستم نصب می‌کنم و مطمئن می‌شوم که همه‌چیز برای شروع کار با SQL آماده است.

---

# PostgreSQL چیست؟

PostgreSQL یک سیستم مدیریت پایگاه داده رابطه‌ای (RDBMS) متن‌باز و قدرتمند است که از زبان SQL برای مدیریت داده‌ها استفاده می‌کند.

در طول این مسیر یادگیری، تمام مثال‌ها، تمرین‌ها و پروژه‌ها را با PostgreSQL انجام خواهم داد.

---

# نصب PostgreSQL

نسخه مناسب سیستم‌عامل خود را از وب‌سایت رسمی PostgreSQL دانلود و نصب می‌کنم.

در هنگام نصب معمولاً این گزینه‌ها نمایش داده می‌شوند:

* PostgreSQL Server
* pgAdmin 4
* Command Line Tools
* Stack Builder

تنها موردی که فعلاً نیازی به آن ندارم، **Stack Builder** است.

---

# تعیین رمز عبور

در هنگام نصب باید برای کاربر پیش‌فرض PostgreSQL یک رمز عبور تعیین کنم.

نام این کاربر به‌صورت پیش‌فرض:

```text
postgres
```

است.

این رمز عبور را در جای امنی نگه می‌دارم، زیرا در ادامه دوره برای اتصال Python به PostgreSQL به آن نیاز خواهم داشت.

---

# بررسی نصب

برای اطمینان از نصب صحیح، ترمینال را باز می‌کنم و دستور زیر را اجرا می‌کنم:

```bash
psql --version
```

اگر نسخه PostgreSQL نمایش داده شود، یعنی نصب با موفقیت انجام شده است.

نمونه خروجی:

```text
psql (PostgreSQL) 17.x
```

---

# ورود به PostgreSQL

برای ورود به محیط خط فرمان PostgreSQL دستور زیر را اجرا می‌کنم:

```bash
psql -U postgres
```

در صورت درخواست، رمز عبور را وارد می‌کنم.

اگر اتصال با موفقیت انجام شود، اعلان زیر را مشاهده خواهم کرد:

```text
postgres=#
```

از این لحظه وارد محیط PostgreSQL شده‌ام و می‌توانم دستورات SQL و دستورات مخصوص `psql` را اجرا کنم.

---

# اولین دستور

برای مشاهده تمام پایگاه‌های داده موجود:

```sql
\l
```

یا:

```sql
\list
```

خروجی معمولاً شامل این پایگاه‌های داده است:

* postgres
* template0
* template1

---

# خروج از PostgreSQL

برای خروج از محیط `psql` دستور زیر را اجرا می‌کنم:

```sql
\q
```

در این فصل:

* با ابزارهای اصلی آن آشنا شدم.
