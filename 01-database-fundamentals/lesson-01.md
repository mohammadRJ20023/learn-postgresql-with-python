# Introduction

قبل از اینکه اولین Query خودمان را بنویسیم، باید بدانیم اصلاً با چه چیزی قرار است کار کنیم.

اگر این مفاهیم را درست یاد بگیریم، از فصل بعد تقریباً تمام تمرکز ما روی کدنویسی خواهد بود.

---

# What is Data?

قبل از اینکه درباره Database صحبت کنیم، باید بدانیم Data چیست.

Data یعنی هر اطلاعات خامی که بتوان آن را ذخیره کرد.

مثال:

نام یک کاربر

```text
Ali
```

سن

```text
23
```

شماره موبایل

```text
0912*******
```

قیمت یک محصول

```text
1250000
```

همه این‌ها Data هستند.

به‌تنهایی ارزش زیادی ندارند؛ اما وقتی کنار هم قرار بگیرند، اطلاعات مفیدی ایجاد می‌کنند.

---

# What is a Database?

Database مجموعه‌ای از داده‌های مرتبط است که به صورت منظم ذخیره شده‌اند تا بتوانیم:

* ذخیره کنیم.
* جستجو کنیم.
* ویرایش کنیم.
* حذف کنیم.
* گزارش بگیریم.

به زبان ساده:

> Database مثل یک انبار بسیار منظم برای نگهداری اطلاعات است.

---

## مثال واقعی

فرض کنید قرار است یک فروشگاه اینترنتی طراحی کنیم.

چه اطلاعاتی باید نگهداری شود؟

* کاربران
* محصولات
* سفارش‌ها
* پرداخت‌ها
* آدرس‌ها
* دیدگاه‌ها

اگر همه این اطلاعات را داخل فایل‌های Word یا Excel ذخیره کنیم، بعد از مدتی پیدا کردن، ویرایش و مدیریت آن‌ها بسیار سخت می‌شود.

Database دقیقاً برای حل همین مشکل ساخته شده است.

---

# DBMS چیست؟

Database فقط داده‌هاست.

برای مدیریت این داده‌ها به یک نرم‌افزار نیاز داریم.

این نرم‌افزار را Database Management System یا به اختصار DBMS می‌نامیم.

وظایف DBMS:

* ذخیره اطلاعات
* حذف اطلاعات
* ویرایش اطلاعات
* جستجوی اطلاعات
* مدیریت هم‌زمان کاربران
* جلوگیری از خراب شدن داده‌ها
* مدیریت امنیت
* تهیه نسخه پشتیبان

---

## معروف‌ترین DBMSها

* PostgreSQL
* MySQL
* MariaDB
* SQLite
* Oracle Database
* Microsoft SQL Server

در این بوت‌کمپ از PostgreSQL استفاده خواهیم کرد.

---

# SQL چیست؟

SQL مخفف Structured Query Language است.

SQL یک زبان برنامه‌نویسی عمومی مانند Python نیست.

بلکه زبانی است که برای ارتباط با پایگاه داده طراحی شده است.

با SQL می‌توانیم:

* داده اضافه کنیم.
* داده حذف کنیم.
* داده ویرایش کنیم.
* داده جستجو کنیم.
* گزارش تهیه کنیم.

تقریباً تمام DBMSهای رابطه‌ای از SQL استفاده می‌کنند.

---

# PostgreSQL چیست؟

PostgreSQL یک DBMS است.

SQL یک زبان است.

این دو را با هم اشتباه نگیرید.

رابطه آن‌ها مانند Python و کدهای Python است:

* Python → زبان
* PostgreSQL → نرم‌افزار مدیریت پایگاه داده
* SQL → زبان صحبت کردن با PostgreSQL
