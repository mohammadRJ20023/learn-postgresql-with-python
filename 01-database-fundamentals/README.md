## Why this chapter?

Before working with PostgreSQL, I need a solid understanding of database fundamentals. This chapter builds the foundation for everything that follows, including SQL, database design, and Python integration.

The goal is not to memorize terms but to understand how relational databases work.

## What I'll learn

* Database
* DBMS
* SQL
* PostgreSQL
* Tables, Rows, Columns
* Primary Keys
* Foreign Keys
* Relationships
* ACID
* Introduction to Normalization
