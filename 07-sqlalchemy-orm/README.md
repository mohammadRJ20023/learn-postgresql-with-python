# SQLAlchemy ORM

## 🇮🇷 فارسی

در این فصل یاد می‌گیرم چگونه بدون نوشتن مستقیم SQL، با استفاده از SQLAlchemy ORM با PostgreSQL کار کنم.

هدف این فصل حذف SQL نیست؛ بلکه یادگیری استفاده از ORM در کنار دانشی است که از SQL به دست آورده‌ام.

در پایان این فصل می‌توانم مدل‌های دیتابیس را تعریف کنم، عملیات CRUD انجام دهم و ارتباط بین جدول‌ها را با SQLAlchemy پیاده‌سازی کنم.

---

### مباحث

* Installing SQLAlchemy
* Engine
* Declarative Base
* Models
* CRUD
* Relationships
* Mini Project

---

## 🇺🇸 English

In this chapter, I learn how to use SQLAlchemy ORM with PostgreSQL.

The goal is not to replace SQL knowledge, but to build applications faster while understanding what happens behind the scenes.

After completing this chapter, I will be be able to define models, perform CRUD operations, and work with relationships using SQLAlchemy ORM.
