# Advanced SQL

## 🇮🇷 فارسی

در این فصل با قابلیت‌های پیشرفته SQL آشنا می‌شوم.

هدف این فصل فقط نوشتن Query نیست، بلکه یاد می‌گیرم چگونه از داده‌ها گزارش تهیه کنم و اطلاعات موردنیاز را استخراج کنم.

بعد از پایان این فصل می‌توانم Queryهایی بنویسم که در پروژه‌های واقعی و پنل‌های مدیریتی بسیار رایج هستند.

---

### مباحث

* Aggregate Functions
* GROUP BY
* HAVING
* DISTINCT
* LIKE
* BETWEEN
* IN
* Subquery
* Common Table Expressions (CTE)
