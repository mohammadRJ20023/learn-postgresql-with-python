# Python & PostgreSQL

## 🇮🇷 فارسی

در این فصل یاد می‌گیرم چگونه از داخل Python به PostgreSQL متصل شوم و عملیات CRUD را انجام دهم.

تا قبل از این، تمام Queryها را داخل pgAdmin اجرا می‌کردم. از این فصل به بعد، همه Queryها از داخل برنامه Python اجرا می‌شوند.

در پایان این فصل می‌توانم یک برنامه Python بنویسم که اطلاعات را از PostgreSQL بخواند، ذخیره کند، ویرایش کند و حذف کند.

---

### مباحث

* Installing psycopg
* Database Connection
* SELECT
* INSERT
* UPDATE
* DELETE
* Parameterized Queries
* Mini Project

## 🇺🇸 English

In this chapter, I learn how to connect Python to PostgreSQL using psycopg and perform CRUD operations.

After completing this chapter, I will be able to build Python applications that interact with PostgreSQL databases safely and efficiently.
